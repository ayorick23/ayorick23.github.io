# 0009. El sitio presenta a Dereck como analista de datos

**Estado:** Aceptada
**Fecha:** 2026-11-14 (registrada retroactivamente el 2026-11-20)

## Contexto

El sitio presentaba a Dereck como perfil de Data Science / ML / MLOps, pero los puestos a los
que aplica (y los reclutadores que lo contactan) son de analista de datos.

## Decisión

El titular es **analista de datos** (Data Analytics · BI · Machine Learning). Machine
Learning, MLOps e ingeniería de datos se muestran como diferenciales frente a un analista
junior, no como titular. Esto se aplicó al hero, la meta descripción, el título de
herramientas, el orden de capacidades, "Sobre mí", contacto y las og:image.

## Alternativas consideradas

- **Mantener el titular de Data Science / MLOps:** no coincide con los puestos a los que aplica.

## Por qué

El portafolio tiene que responder a la pregunta que se hace el reclutador del puesto real.

## Consecuencias

- Todo texto nuevo (hero, meta, contacto, "Sobre mí", casos de estudio) mantiene ese tono.
- La frase del hero se considera genérica y se revisará con el rediseño del hero
  (`docs/roadmap.md`).
