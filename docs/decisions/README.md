# Decisiones de arquitectura (ADRs)

Cada archivo registra una decisión: el contexto, qué se decidió, qué alternativas había y por
qué. Una ADR aceptada no se edita; si la decisión cambia, una ADR nueva la supera. Se crean con
`/nueva-adr`.

Las 0001–0013 son **retroactivas**: se escribieron el 2026-11-20 a partir del `CLAUDE.md`, los
commits y las notas de sesión, para decisiones que ya estaban tomadas. Su fecha es la de la
decisión original.
