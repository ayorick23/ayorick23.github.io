sections:
  - heading: "Contexto"
    body: "El churn no es únicamente un problema de clasificación; también es un problema de decisión. El objetivo de este proyecto es identificar clientes con una mayor probabilidad de abandono mientras se construye un flujo de trabajo reproducible, evaluable y mantenible más allá de un solo notebook."
  - heading: "Enfoque"
    body: "El proyecto sigue un flujo estructurado de Machine Learning: validación y exploración de datos, ingeniería de variables, construcción de baselines, comparación de modelos y evaluación mediante métricas alineadas con el objetivo del problema."
  - heading: "Ingeniería"
    body: "El flujo de modelado incorpora seguimiento de experimentos con MLflow, versionado de datos y pipelines con DVC, pruebas automatizadas, controles de calidad de código y contenerización con Docker. El proyecto está diseñado alrededor de la reproducibilidad y no de una experimentación aislada."
  - heading: "MLOps"
    body: "El ciclo de vida del modelo se trata como un sistema: los experimentos se registran, los datos y el código se versionan, los modelos se evalúan contra criterios definidos y el reentrenamiento puede incorporarse a un flujo automatizado."
  - heading: "Resultado"
    body: "El resultado no es únicamente un clasificador entrenado, sino un proyecto de ML completo y reproducible que demuestra cómo llevar un modelo desde la experimentación hacia un flujo de trabajo mantenible y orientado a producción."
